# web-occult — Claude Code guide

Static site at occult.alokm.com (Cloudflare Pages, Direct Upload from this machine via `scripts/deploy.sh` — deliberately no git integration or Actions). See README.md for the pipeline.

Rules that are easy to break:
- **The event list is hand-curated in `seed.json` and every number is computed** — never paste
  timings from Occult/IOTA or in-the-sky.org (their copyrighted output; it has no map elements anyway).
  Candidates: `python lookup/generate/occultation_event.py --scan 2026-09-11 2029-01-01` in kaalshodh/api.
- `data/*.json` is generated in the kaalshodh repo (needs DE431 + Skyfield); don't hand-edit.
- `site/` is generated by `scripts/build_pages.py`; edit the builder, not the HTML.
- Mean limb (R = 1737.4 km): contacts are ±2 s; limit lines ≈ grid resolution. Say so on pages, don't imply IOTA precision.
- Scope now: lunar occultations of grahas and bright stars. Asteroid occultations and grazes at IOTA precision are deferred.
- Analytics is the shared alokm.com GA4 property (`G-GD7LT48Y79`, same as eclipse/zsd/inc), emitted by `head()` in the builder. No other third-party JS. Text pages should stay under ~50 KB gzipped.
